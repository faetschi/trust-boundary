Static design mockup v3

This file is a static preview of the redesigned web chat. Its tokens, CSS modules, class names and wording come from the React UI at frontend/src (HEAD 60ca5b0); the running UI is /app/ on the gateway. The data is the demo fixture (--demo, session "Add /healthz and run tests"). Anything drawn for review and absent from the fixture carries a dashed mock sample label.

Wired in this file: the theme switch (System, Light, Dark), the Chat and Trajectory tabs (arrow keys, Home and End), the Governance drawer below 1180 px, Escape, and the record inspector (close with its button, reopen by clicking the selected row). Filters, grouping, search and the other rows are static samples of the default state.

Deep links for review: #theme=dark, #view=trajectory, #drawer=open (combine with &).

Claim boundary. G1 is false, H1 is unexecuted, containment is not-established, and claim-bearing is false. Nothing in this mockup is evidence of G1 or H1. A static render checks layout and wording only.

State vocabulary

Every shape carries text (a chip or a word), so no state is conveyed by colour alone. Shapes are drawn by StateDot.module.css and chips by Chip.module.css, copied unchanged.

  • succeededok: solid circle, verified success (not reachable from the demo)
  • ALLOWallow: 2 px ring, a permission and not an outcome
  • denieddeny: solid square, refused, denied or failed (not a success)
  • reportedreported: 2 px dashed ring, succeeded but not independently verified
  • unknownunknown: 2 px dotted ring, no terminal outcome retained
  • lostlost: solid diamond, the outcome was not recorded (not a success)
  • pendingpending: 1 px hollow ring, no outcome yet
  • unavailableidle: solid grey dot, no verdict or outcome, or not available

Design notes

Token tiers. Tier 1 is the static ramp per theme (--tb-s-*; components never read it). Tier 2 is the alias layer that components read (--background, --state-*, --source-*). Tier 3 is theme-free geometry (--space-*, --radius-*, --text-*). The values are copied verbatim from styles/tokens.css. Light is the default, dark follows the OS or data-theme="dark", and System removes the attribute.

Type and shape. System font stacks only, with no webfonts. Body text is 14/22, secondary 13/20, small 12/18 and micro 11/14. Radii step 4, 8, 12, 16, 20 and 28. Hairline borders come before shadows. Colour is reserved for state and source.

Contrast. The palette values are the proposed values checked by docs/design/contrast.mjs. Re-running it reproduces docs/design/contrast-output.txt exactly: 24 text and non-text pairs per theme, with 0 proposed failures. That is a calculation from the palette, not a browser measurement. Pairs that are not in that table are not claimed.

Mock versus running UI. This file is static. The running UI is /app/. The CSS modules are copied unchanged, with class names prefixed per module (for example cv- for the chat view and tv- for the trajectory) so one stylesheet can hold them. Markup and wording mirror the running UI's DOM, which was read in a capture. Times are the capture's local time (UTC+2), while the running UI shows the viewer's time zone.

Differences from the running UI (intentional). The mock samples listed above are not in the demo. The trajectory opens with the DENY record selected and its record inspector shown, while the running UI shows governance until a row is clicked. The Chat transcript expands the go-test card to show its decision and result steps, so the turn is taller here (791 px against 507 px in the running UI, where cards start collapsed). The sample jump pill sits in the sample flow, where the running UI's pill is sticky. The running UI mounts only the selected panel; this file keeps both panels in the DOM and hides one. Filters, grouping and search are not wired.

Accessibility. Named landmarks (header, nav, main, aside, footer). Tabs use roving focus with arrow keys. The theme control is a toolbar with aria-pressed. The Governance toggle carries aria-controls and aria-expanded. The live region is role="status". Focus is a 2 px ring. Reduced motion is switched off globally in base.css. Under forced colours the state shapes keep their borders, and the diamond and square keep their shapes.
