# Developer tools

Source-only tools that are not part of the release packages or a CI gate. Each one is kept on purpose; do not delete one as clutter. Run them from a source checkout.

| Tool | Purpose | Entry command | Needs | Status |
| --- | --- | --- | --- | --- |
| `supervisor/cmd/tbound-provider` | One live provider exchange through the broker: one prompt, one declared-tool call, then a redacted one-line summary (status, response id, whether the four-tool manifest was respected). Prints `containment=not-established g1=false`; it is a provider smoke, not evidence. | `cd supervisor && go run ./cmd/tbound-provider` | Go; `TBOUND_OPENCODE_GO_API_KEY` or `TBOUND_OPENCODE_GO_API_KEY_FILE` (the key is never printed). Makes a real, billed call. | Current as a manual smoke. Not built by `scripts/build-release.sh`. Its unit tests (`main_test.go`) run offline in `go test ./...`. The durable provider path is covered by [providers](../runtime/providers.md). |
| `extensions/webchat/scripts/ui-qa.mjs` | Browser QA of the React `/app/` client over the DevTools protocol: keyboard walk, responsive layouts, theme, reconnect, forced colours, console and network checks (checks A to L, listed in the file header). Writes a JSON receipt and PNG files to `extensions/webchat/docs/webchat/qa/`. | `cd extensions/webchat && node scripts/ui-qa.mjs --url http://127.0.0.1:PORT` | Node 22 or later (24.x pinned); Chrome, Chromium or Edge (`--chrome` or `CHROME_BIN`); a demo gateway already running on a fresh loopback port, never 8791. Check G also needs `--gateway-stop` and `--gateway-start`. | Current for the optional, frozen web chat. Opt-in; not in `make test`, CI or any core gate. Check A runs `csp-smoke.mjs`, and check B still exercises `/legacy/`. Compare its coverage before any retirement. |
| `extensions/webchat/scripts/csp-smoke.mjs` | Headless-browser Content-Security-Policy smoke for the gateway, with a negative-control observer. | `make extension-webchat-csp` (set `CSP_URL` to target a running gateway) | Node >=22; Chrome, Chromium or Edge; Go 1.27.x unless `CSP_URL` targets an already-running gateway. | Current; the `webchat-extension` workflow's `csp-smoke` job runs it on manual dispatch only. |
| `supervisor/cmd/tbound-hint-eval` | Offline comparison of recorded decision-model choices for denial hints. Never calls a provider. | `cd supervisor && go run ./cmd/tbound-hint-eval` | Go. | Current; see [denial hint providers](../design/denial-hint-providers.md). |
| `supervisor/cmd/tbound-panel` | Blinded AI construct-review panel with `--estimate`, `--dry-run` and `--live` modes. | `cd supervisor && go run ./cmd/tbound-panel --estimate ...` | Go; `OPENROUTER_API_KEY` for `--live` only. | Current, optional; see the [panel guide](panel-run.md). |
| `infra/freeze/tools/` | Owner-side freeze, gate and guest-chain scripts. | See the [freeze kit](../../infra/freeze/README.md). | Owner-side `freeze.sh`, `all.sh` and `gate.sh` run in WSL or on Linux and refuse Git Bash. `guest-chain.sh`, `gssh.sh` and `pull-receipts.sh` also run from Git Bash, with the configured WSL helpers. Guest access. | Current; owner-run. |

The main product and thesis commands (`tbound`, `tbound-run`, `tbound-profile`, `tbound-doctor`) are covered in [setup](setup.md) and [reproduction](reproduce.md). To see which local command reproduces each CI job, read [Validation lanes and CI jobs](reproduce.md#validation-lanes-and-ci-jobs).
